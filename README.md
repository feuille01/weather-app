# 🌤️ Приложение «Погода»
Простое веб-приложение, которое отображает текущую погоду и местоположение на карте по заданным географическим координатам. Создано без использования сторонних фреймворков.

## 📌 Основные возможности
- Ввод координат (широта и долгота) с автоматической заменой запятых на точку.
- Получение актуальной погоды указанного места через WeatherAPI.
- Интерактивная карта 2ГИС.
- Поддержка нескольких виджетов.
- Хранение виджетов пользователя между перезагрузками.
- Простой и лаконичный интерфейс.

## 🌐 Используемые API
- WeatherAPI – для получения города, страны, погоды, изображения погодных условий, влажности, ветра, видимости.
- 2ГИС – для отображения карты в указанной точке.

## 📊 Отображаемая информация
Для каждой локации в виджете отображается:  
  
🏙️  Город и страна  
🌤️  Изображение погодных условий  
🌡️   Текущая температура и ощущается как  
☁️  Описание погоды (например, «облачно», «дождь»)  
💧   Влажность (%)  
💨  Скорость ветра и порывы (в м/с)  
👁️  Видимость (в км)  
🗺  Местоположение на карте 2ГИС  
> Иконка погоды автоматически меняется в зависимости от условий (солнце, дождь, облака и т.д.).

## 🛠️ Технические особенности
- Без фреймворков.
- Валидация ввода:
  - Проверка на числовые значения: широта: от -90 до 90, долгота: от -180 до 180.
- Асинхронные запросы через fetch + async/await.
- Модульный и читаемый код:
  - Функции короче 25 строк
  - Осмысленные названия
  - Чёткое разделение логики
- Управление виджетами:
  - Удаление виджета кнопкой ×

## 💾 Хранение данных
- Все добавленные виджеты сохраняются в localStorage.
- При перезагрузке страницы виджеты восстанавливаются автоматически.

## ▶️ Как запустить
1. Склонируй репозиторий:
```bash
git clone 
```
2. Получи API-ключи:
- WeatherAPI → вставь в переменную API_KEY
- 2ГИС → вставь в переменную MAP_2GIS_KEY
3. Открой файл index.html в браузере.
